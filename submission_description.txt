This Week 2 project presents an Exploratory Data Analysis (EDA) and Visualization of the Titanic passenger dataset using Python. The main objective of the project was to understand the structure and quality of a public dataset and extract meaningful insights through statistical analysis and visualization. The project was completed using Pandas for data loading, inspection, cleaning, transformation, grouping and descriptive statistics. Matplotlib and Seaborn were used to create clear and properly labelled visualizations.

The analysis begins with an overview of the dataset, including the number of rows and columns, data types and missing values. Missing values were examined carefully, and suitable transformations were applied for analysis, including median-based filling for age and mode-based filling for embarkation. The project then analyzes passenger survival, gender distribution, passenger class distribution and embarkation locations.

Several visualizations were created to identify important patterns. These include survival distribution, gender distribution, survival by gender, passenger class distribution, survival by class, survival rates by gender and class, embarkation distribution and a correlation heatmap. The results show that survival was strongly associated with gender and passenger class in the observed dataset. Female passengers had a much higher survival rate than male passengers, while first-class passengers had a higher survival rate than second- and third-class passengers.

The final report includes the EDA process, Python code snippets, visualizations and interpretations of the findings. The complete Python script is also provided so that the analysis can be reproduced. This project demonstrates practical use of Python libraries for data analysis and develops an understanding of how visualization can help identify trends, relationships and meaningful insights from real-world data.
