# Week 2 - Titanic EDA and Visualization

## Project Title
Exploratory Data Analysis and Visualization of the Titanic Passenger Dataset

## Objective
Analyze the Titanic dataset using Python, Pandas, Matplotlib and Seaborn.

## Dataset
Standard Seaborn Titanic dataset:
https://github.com/mwaskom/seaborn-data/blob/master/titanic.csv

## Run
```bash
pip install -r requirements.txt
python titanic_eda.py
```

The script creates visualizations in the `charts` folder.
